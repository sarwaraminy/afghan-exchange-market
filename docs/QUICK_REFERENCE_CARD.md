# Hawala System - Quick Reference Card
## Version 2.0 - Daily Use Guide

---

## 🔐 SECRET PIN RULES

### Creating Transaction:
1. System generates 4-digit PIN
2. **Write PIN on receipt immediately**
3. Give receipt to sender
4. Sender shares PIN with receiver **verbally** (not SMS!)

### Processing Payout:
1. **Always ask for PIN**: "What is the 4-digit PIN?"
2. Receiver must provide correct PIN
3. System verifies PIN before payout
4. ❌ **NO PIN = NO PAYOUT**

---

## 📋 TRANSACTION WORKFLOW

### Creating (Sending):
```
1. New Transaction
2. Enter sender/receiver info
3. Enter amount + commission
4. SAVE THE SECRET PIN! 🔑
5. Write on receipt
6. Call receiving hawaladar
```

### Payout (Receiving):
```
1. Search by reference code
2. Verify Tazkira (ID)
3. Verify phone number
4. ASK FOR SECRET PIN
5. Enter all details
6. Complete payout
7. Hand cash to receiver
```

---

## ⏰ EXPIRATION RULES

| Age | Status | Action |
|-----|--------|--------|
| 0-3 days | 🟢 OK | Process normally |
| 4-6 days | 🟡 Warning | Process soon! |
| 7+ days | 🔴 Expired | Cannot process - contact sender |

**Expired Transaction?**
→ Receiver contacts sender
→ Sender creates NEW transaction
→ New code + new PIN

---

## 🆔 IDENTITY VERIFICATION

### Required at Payout:
✅ Tazkira Number (6-20 digits)
✅ Phone Number (8-20 digits)
✅ Secret PIN (4 digits)

### Check:
- Name matches Tazkira
- Photo matches person
- Phone number matches transaction

**If anything doesn't match:**
→ Contact sender to verify
→ Don't process until confirmed

---

## 💰 TRANSACTION LIMITS

### Default Limits:
- **Max Single**: 100,000
- **Max Daily**: 500,000

**"Daily Limit Exceeded" Error?**
→ Wait until tomorrow
→ Or contact admin to increase

## 🚨 COMMON ERRORS & FIXES

| Error | Cause | Fix |
|-------|-------|-----|
| Invalid PIN | Wrong PIN entered | Ask receiver to verify with sender |
| Transaction Expired | >7 days old | Create new transaction |
| Already Completed | Paid already | Check transaction history |
| Daily Limit Exceeded | Too much today | Wait or increase limit |
| Insufficient Balance | Not enough funds | Make deposit |

## 🔍 TROUBLESHOOTING FAST

### Receiver Forgot PIN?
1. Receiver calls sender
2. Sender verifies identity
3. Sender shares PIN
4. Process payout

### Can't Find Transaction?
1. Check reference code format
2. Verify each character (O vs 0, I vs 1)
3. Contact sending hawaladar

### System Prevents Payout?
1. Check expiration date
2. Verify PIN is correct
3. Check if already completed
4. Confirm you're authorized for this hawaladar
